# Rigid versus ReAct

This project displays two basic setups of a simulated, automated workflow involving fetching contact details and sending an email to that contact.

Langchain and Langgraph frameworks are implemented to define the workflow.

The first part of the project displays the rigid workflow where all nodes are defined, and the end-to-end workflow is hardcoded.

The second part of this project(still open) displays the same workflow tied to an LLM that's given the capability of the ReAct node.
